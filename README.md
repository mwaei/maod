Клиентский мод: панель управления для Baritone (по умолчанию клавиша `5`).

## Вкладка «Животные»
- **Автоубийство животных** — вкл/выкл.
- **Кого бить**: «выбранных» или «всех животных».
- **Список**: названия через пробел, как в игре (`cow pig sheep chicken`). Кнопки-пресеты добавляют/убирают животное (выбранные помечены `+`).
- **Дистанция** 1–5 блоков, **детёнышей не бить** (по умолчанию да, чтобы не убивать будущее стадо).
- Приручённые питомцы не трогаются никогда.

### Названия животных
| Животное | Название |
|---|---|
| Корова | `cow` |
| Гриб-корова | `mooshroom` |
| Свинья | `pig` |
| Овца | `sheep` |
| Курица | `chicken` |
| Кролик | `rabbit` |
| Коза | `goat` |
| Лиса | `fox` |
| Лама | `llama` |
| Лошадь / осёл / мул | `horse` / `donkey` / `mule` |
| Панда | `panda` |
| Черепаха | `turtle` |
| Верблюд | `camel` |

Рыбы и кальмары не входят в «животных» (в игре это другой класс существ).

## Вкладка «Сундуки» (автосклад)
Три режима: **всё** / **только из списка** / **всё, кроме списка**.
Список — id предметов через пробел; достаточно части названия (`ore` — все руды, `stone` — всё каменное).
Кнопка «Предмет из руки» добавляет id предмета, который ты держишь. Хотбар всегда остаётся у тебя.

## Сборка
Положи `BaritoneUIClient.java` в `src/main/java/com/example/baritoneui/client/` Fabric-проекта и собери `./gradlew build`.
Готовый `.jar` из `build/libs` кидай в папку `mods`.
